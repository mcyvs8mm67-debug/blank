# FRONTLINE PROTOCOL — Unity FPS

Unity 6 FPS foundation. Runtime-generated dockyard level, first-person movement, three firearms, enemy bots, HUD, synthesized audio, explosive barrels and breakable glass.

## Open
Open the `FrontlineProtocol` folder in Unity Hub using Unity 6.0.35f1 with WebGL Build Support. Press Play; the runtime bootstrap builds the level automatically.

## Controls
WASD move · Shift sprint · Ctrl crouch · Space jump · Mouse aim · LMB fire · RMB ADS · R reload · 1/2/3 weapons · Esc pause.

## Web build
A GitHub Actions workflow is included at the repository root. Configure `UNITY_LICENSE`, `UNITY_EMAIL`, and `UNITY_PASSWORD` repository secrets and set GitHub Pages source to GitHub Actions. Unity Editor compilation is required; the compiled WebGL output is generated by Actions.
