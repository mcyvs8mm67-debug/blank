# FRONTLINE PROTOCOL — Browser FPS
A Three.js/WebGL tactical first-person shooter playable in a modern desktop browser.

## Play
Open the deployed site and navigate to /game/. Select one of three maps and deploy. The Three.js modules are loaded from jsDelivr, so the game requires an internet connection.

## Controls
- WASD: move; Shift: sprint; Ctrl: crouch/slide; Space: jump
- Mouse: look; left click: fire; right click: aim
- R: reload; 1 / 2 / 3: assault rifle / precision rifle / pistol
- U: UAV; I: airstrike; O: attack drone; Esc: pause/settings

## Browser build
This game is built with Three.js and WebGL. It is separate from the Unity prototype in /FrontlineProtocol.
